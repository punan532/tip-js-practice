Во втором терминале из этой же папки запустить `npm run dev`. Адрес: http://127.0.0.1:5173/?trace=1. Параметр trace включает лог загрузки для КР3. API по умолчанию доступен на порту 5505.

Хук useTaskData сохраняет последний успешный снимок, отменяет устаревшее чтение и ведёт отдельные ошибки чтения и записи. После подтверждённой записи выполняется GET с актуальными фильтрами.
